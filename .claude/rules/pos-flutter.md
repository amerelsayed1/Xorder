# xorder-pos (Flutter desktop) — verified 2026-10-22; paths re-verified 2026-11-08 (`development` `7fa0d06`)

- Defer to `apps/xorder-pos/CLAUDE.md`; it is authoritative over older `docs/pos/*` prose. Before significant changes follow `.claude/rules/knowledge.md` (`/project-documentation context <feature> <phase>`).
- Workspace (pos-split-apps): `packages/shared_module` (the shared till, package `shared_module`), `packages/xorder_pos_test_support` (fakes, fonts, PostgreSQL fixture; dev only), `apps/xorder_pos_offline` (back office `lib/features/admin/`), `apps/xorder_pos_cloud` (sync `lib/data/cloud/`, `integration_test/`). `lib/…` below means `packages/shared_module/lib/…` unless an app is named. Mode-only code lives in its app; `packages/shared_module` must import neither app (`test/package_boundaries_test.dart`), and neither app depends on the other. The waiter handheld (waiter-app, 2026-11-09): `packages/xorder_waiter_link` (pure-Dart LAN link: wire, client, server) and `apps/xorder_pos_waiter` (Android/iOS app); the handheld depends on the link package only — never on `shared_module`, not even as a dev dependency (its `test/package_boundaries_test.dart`) — and the till serves it from `lib/features/waiter_link/`. Prices, tax and the table version check stay on the till.
- Datastores (pos-cloud-single-till-sqlite, 2026-11-08): Offline app = PostgreSQL; Cloud app = one encrypted SQLite file per till (`apps/xorder_pos_cloud/lib/data/local/cloud_datastore.dart`). Repositories are written once against `lib/data/sql/` (`SqlDatabase`, `Sql.named`, `row_reads.dart` for dates/booleans/lists — never `as DateTime`/`as bool` on a row); PostgreSQL-only SQL that SQLite cannot take goes behind `SqlDatabase.dialect`. A new PostgreSQL migration on a cloud-till table needs a `sqliteUpgrades` entry in `lib/data/sqlite/sqlite_migrator.dart`. Prove both engines: `POS_TEST_ENGINE=sqlite flutter test <suite>` (also run by `scripts/check.sh`).
- Layers: `lib/core` → `lib/domain` (plain Dart models, repository contracts, pure `services/ticket_engine.dart`) → `lib/data/{postgres,cloud,fakes,unconfigured}` (shared `data/cloud` is only `cloud_api` + `device_token_vault`) → `lib/features/<area>`. `lib/domain` and `lib/core/money` never import Flutter. UI depends only on `lib/domain/repositories`; implementations are bound in `lib/app/providers.dart` (Riverpod, one file). Routing is go_router; payment, modifier and receipt sheets are dialogs over the sale screen, not routes.
- **Money is integer minor units with a currency exponent; never `double`.** Rates are basis points (`percentBp`), rounding is half-up once at the tax line (`roundHalfUp`). Every ticket mutation goes through `TicketEngine` and returns a new immutable `Ticket`; refusals are `TicketRefusal` data, not exceptions; only draft lines merge, edit or delete; `Ticket.id` is the idempotency key and changes only in `clear()`.
- Design: border-radius 0, no shadows, tokens only from `lib/core/ui/tokens.dart`, house widgets over Material; keyboard-first (every primary action has a key and a `KeyChip`); Arabic and English.
- Resilience: a till never crashes or bricks. Unknown server enums fall back, unparseable input returns null, an expired licence blocks the next shift, never the open one; cash-up, reprint and export are never gated on licence state.
- Offline-first: the sync queue is the `pos_outbox` table drained by `apps/xorder_pos_cloud/lib/data/cloud/outbox_drain.dart`. Integrate only against contracts marked `READY` in `apps/xorder-cloud/docs/coordination/BACKEND_TO_POS.md` (compare with the POS copy; they can drift); never assume a cloud change is deployed; file new needs as `POS-BE-xxx` in `POS_TO_BACKEND.md` instead of inventing endpoints.
- Verify: `cd apps/xorder-pos && scripts/check.sh` from the repo root runs every member (analyse, unit, PostgreSQL; needs a local server; a path argument narrows it to `shared_module`). One member: `cd packages/shared_module && flutter analyze && flutter test [path]` (or an app folder; green with no database, `integration`-tagged suites self-skip without `POS_PG_HOST`). Run: `cd apps/xorder_pos_offline && flutter run -d macos` (or `apps/xorder_pos_cloud`). CI does not run tests. Widget tests pump at 1440×900. Do not read `pubspec.lock` whole.
