# Module documents

One file per module, named by the module slug in `docs/FEATURE_INVENTORY.md` (for example `shifts-and-cash.md`). Created by `/project-documentation module <name>` from `.claude/skills/project-documentation/templates/MODULE.md`. A module doc explains architecture, shared data and cross-module dependencies; behavior of each feature lives in `docs/features/<slug>/`. Read a module doc only for architecture questions, never to load a whole area into context. Modules without a file here have not been documented yet.
